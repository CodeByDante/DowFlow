<h3 align="center">NekoDrop</h3>

<p align="center">
  <a href="https://github.com/CodeByDante/nekodrop/archive/refs/heads/main.zip">
    <img src="readme-button.svg" width="280" alt="DESCARGAR NEKODROP">
  </a>
</p>

**NekoDrop** es una extensión para descargar video y audio desde el navegador con ayuda de motores instalados en tu PC. Permite elegir calidad, formato y pistas de audio, consultar listas de reproducción y gestionar descargas desde una misma interfaz.
